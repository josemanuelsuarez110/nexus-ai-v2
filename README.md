# 🚀 Nexus AI - DevSecOps Dashboard

**Nexus AI** es una plataforma centralizada de DevSecOps diseñada para proporcionar visibilidad total sobre el estado de tus proyectos, la seguridad de tu código y la calidad de tus implementaciones.

## ✨ Características
- 🔐 **Autenticación Segura:** Login con Email/Password y OAuth con GitHub (Supabase).
- 📊 **Dashboard Interactivo:** Visualización de métricas clave.
- 🎨 **UI/UX Premium:** Diseño moderno con Tailwind CSS.
- 🛡️ **Protección de Rutas:** Middleware robusto para proteger el dashboard.

## 🛠️ Stack Tecnológico
- **Framework:** Next.js 15 (App Router)
- **Base de Datos y Auth:** Supabase
- **Estilos:** Tailwind CSS
- **Despliegue:** Vercel
